# Wallet Ledger API

Sexto proyecto del programa **Bankaool .NET Fintech Bridge Lab**.

API REST con ASP.NET Core Web API para practicar conceptos de ledger financiero.

## Objetivo

Construir una API tipo wallet ledger usando movimientos contables:

- Debit
- Credit

## Stack

- Ubuntu
- .NET 8
- C#
- ASP.NET Core Web API
- Swagger/OpenAPI
- Postman

## Conceptos principales

| Concepto fintech | Significado |
|---|---|
| Ledger | Libro contable de movimientos |
| Credit | Entrada de dinero / aumenta saldo |
| Debit | Salida de dinero / reduce saldo |
| Balance | Resultado de créditos menos débitos |
| Entry | Registro individual del ledger |
